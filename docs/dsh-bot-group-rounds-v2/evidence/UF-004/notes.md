# UF-004 删房间（浏览器实点）

## 分支：房间忙
房间 `room-a62d99ae-92f1-4374-b3b1-15c5b7b8aaf1` 讨论中（头部「第 1/3 轮 · 诗人小北 正在发言」）→ 行菜单「删除房间」→ 确认框「删除房间「…」？成员人设和他们的私聊都会保留。」→ 点「删除」。
结果：确认框不关闭，框内错误「房间正在讨论，先停止再删除」；房间文件仍在（`busy.png`）。

## 分支：取消
确认框打开时焦点在「取消」；按 Esc 关闭，或点「取消」关闭。两次之后 deleteGroupSession 请求数都是 0，房间仍是当前选中（`cancel.png`）。
焦点回到房间切换器按钮 `session-select`：行菜单「⋯」在切换器弹层里，弹层已经收起，所以落到仍然可见的切换器按钮上。

## 主路径
删除当前房间 `room-a62d99ae-92f1-4374-b3b1-15c5b7b8aaf1`：确认框（`confirm.png`）→「删除」→ deleteGroupSession 200 ok → toast「已删除房间」，自动选中剩余最新房间 `room-e23155ef…`，列表 3 → 2（`success.png`）。文件对比见 `rooms-diff.txt`。
